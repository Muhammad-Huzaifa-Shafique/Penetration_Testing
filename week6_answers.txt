Answer (on CPU the first words can take a while):

According to [2], SUID binaries can be used for privilege escalation on Linux by exploiting vulnerabilities in shared object (.so) files loaded by the binary. This can be checked by running the following command:

```bash
strace <SUID-BINARY> 2>&1 | grep -i -E "open|access|no such file"
```

If the binary loads a .so file that does not exist, it may be possible to create a malicious .so file that, when loaded, executes a payload that elevates privileges. This can be done by compiling a C file containing the payload into a shared object file, for example:

```bash
gcc -shared -o /path/to/.config/libcalc.so -fPIC /path/to/.config/libcalc.c
```

Then, running the affected SUID binary should trigger the exploit, allowing for potential system compromise.

Additionally, [5] mentions that a SUID binary, such as `/opt/hadoop/bin/container-executor`, can be exploited if it contains a vulnerable path, but this is not directly related to the exploitation of SUID binaries for privilege escalation.

Answer (on CPU the first words can take a while):

To crack password hashes with John the Ripper, you can use the following modes:

*   Wordlist mode: John will simply use a file with a list of words that will be checked against the passwords. See RULES for the format of wordlist files. [4]
*   Incremental mode: This is the most powerful mode. John will try any character combination to resolve the password. [4]
*   Single crack mode: John will try to crack the password using the login/GECOS information as passwords. [4]

To crack specific hash formats, you can use the following:

*   For SSHA512 hashes, decode the base64 value and pass the resulting format to John the Ripper. [3]
*   For PBKDF2_SHA256 hashes, use John the Ripper only when it supports the exact stored format, and do not truncate the digest. [3]
*   For NT hashes, decode the base64 ipaNTHash value and re-encode it as ASCII hex before passing it to John the Ripper. [3]

To extract the hashes, you need to be root in the FreeIPA server, where you can use the dbscan tool to dump Directory Server database contents. [3]

To crack the hash, you can use the following commands:

```bash
john -show passwd
john -restore
john -show -shells:-/etc/expired passwd
```

You can also use the ikescan2john.py script to convert the hash to a format that can be used by John the Ripper. [5]

Note that the specific command to crack the hash will depend on the format of the hash and the mode you want to use.
