id: q02
question: what does the -k flag do in curl, and why would I avoid using it normally?
expect: answer
source: corpus/manpages/curl.man.txt
evidence: By default, every secure connection curl makes is verified
evidence: using this option makes the transfer insecure
must: --insecure
answer:
`-k`, `--insecure` makes curl skip the verification step of a secure connection and proceed without checking. Normally, for TLS, curl verifies that the server's certificate contains the right name for the host in the URL and has been signed by a CA certificate in the cert store; for SFTP and SCP the option makes curl skip the known_hosts verification instead. The man page warns that using this option makes the transfer insecure, which is the reason to avoid it normally.

id: q03
question: what does nmap's -Pn option do and when would I use it?
expect: answer
source: corpus/manpages/nmap.man.txt
evidence: This option skips the host discovery stage altogether
evidence: all 65,536 IP addresses are scanned
must: -Pn
answer:
`-Pn` skips the host discovery stage altogether. Normally Nmap uses that stage to determine active machines for heavier scanning and to gauge the speed of the network, and only runs heavy probing such as port scans, version detection or OS detection against hosts found to be up. With `-Pn` it attempts the requested scanning functions against every target IP address, as if each one were active, so a /16 network means all 65,536 addresses are scanned. Default timing parameters are used, which may result in slower scans. To skip host discovery and the port scan while still allowing NSE to run, use `-Pn -sn` together. The passage describes what `-Pn` does rather than when to use it; the text just before it notes that hosts could be missed when a firewall drops probes or their responses.

id: q04
question: what does sudo -l show me about my own account?
expect: answer
source: corpus/manpages/sudo.man.txt
evidence: If no command is specified, list the privileges for the
must: -l, --list
answer:
With no command given, `sudo -l` lists the privileges for the invoking user (or the user named with `-U`) on the current host. Giving `-l` more than once uses a longer, more verbose format if the security policy supports it. If a command is named and the policy permits it, sudo displays the command's fully-qualified path along with any arguments; if the command is named but not allowed, sudo exits with status 1.

answer:
`-m`, `--hash-type=NUM` selects the hash type by number. id: q07
question: what does the whatweb tool actually identify on a website?
expect: answer
source: corpus/manpages/whatweb.man.txt
evidence: WhatWeb recognises web technologies
evidence: WhatWeb has over 1800 plugins
must: WhatWeb
answer:
WhatWeb identifies websites (its goal is to answer "What is that Website?"). It recognises web technologies including content management systems (CMS), blogging platforms, statistics/analytics packages, JavaScript libraries, web servers and embedded devices, and it also identifies version numbers, email addresses, account IDs, web framework modules and SQL errors. It has over 1800 plugins, each to recognise something different. Its default aggression level, "passive", is the fastest and needs only one HTTP request, which suits scanning public websites; more aggressive modes were developed for penetration tests.

id: q10
question: after getting a basic reverse shell, how do I upgrade it to a full interactive TTY?
expect: answer
source: corpus/hacktricks/src/generic-hacking/reverse-shells/full-ttys.md
evidence: pty.spawn("/bin/bash")
evidence: stty raw -echo; fg
must: pty.spawn
must: stty raw -echo
answer:
First give the shell a pseudo-terminal: `python3 -c 'import pty; pty.spawn("/bin/bash")'` (or `script /dev/null -qc /bin/bash`). Then suspend it with Ctrl+Z and, in your own terminal, run `stty raw -echo; fg` to bring it back in raw mode. Inside the shell, set `export SHELL=/bin/bash`, `export TERM=screen`, match your real terminal size with `stty rows <n> columns <n>` (read your own values first with `stty -a`), then run `reset`.

id: q11
question: how do you test whether a web page is vulnerable to server-side template injection, without going straight to exploiting it?
expect: answer
source: corpus/hacktricks/src/pentesting-web/ssti-server-side-template-injection/README.md
evidence: fuzzing the template
evidence: {{7*7}}
must: SSTI
answer:
Start by fuzzing the template: inject a short sequence of special characters and compare the response to normal input. Signs of a hit are thrown errors that reveal the template engine, or the payload (or part of it) disappearing from the reflection instead of being echoed back unchanged. In a plain-text context, check whether an expression such as `{{7*7}}` or `${7*7}` is actually evaluated, which separates it from ordinary XSS; in a code context, change an input value and see whether the output changes to match, which shows the server is evaluating it rather than just echoing it.

id: q14
question: what is the DCSync technique in Active Directory, and which permissions does an account need to use it?
expect: answer
source: corpus/hacktricks/src/windows-hardening/active-directory-methodology/dcsync.md
evidence: simulates the behavior of a Domain Controller
evidence: Domain Admins, Enterprise Admins, Administrators, and Domain Controllers
must: Domain Controller
answer:
DCSync simulates the behavior of a Domain Controller and asks other Domain Controllers to replicate information, using the Directory Replication Service Remote Protocol (MS-DRSR). Because MS-DRSR is a valid and necessary function of Active Directory, it cannot be turned off or disabled. A full DCSync needs the DS-Replication-Get-Changes and DS-Replication-Get-Changes-All permissions on the domain naming context; by default only the Domain Admins, Enterprise Admins, Administrators and Domain Controllers groups have the required privileges.

id: q15
question: what is a padding oracle, and what makes a system vulnerable to one?
expect: answer
source: corpus/hacktricks/src/crypto/symmetric/README.md
evidence: different errors/timings for bad padding
evidence: you may have a padding oracle
evidence: if the server reveals (directly or indirectly) whether decrypted plaintext has valid PKCS#7 padding
must: padding oracle
answer:
A padding oracle exists when, in CBC mode, the server reveals (directly or indirectly) whether decrypted plaintext has valid PKCS#7 padding. The oracle can be a specific error message, a different HTTP status or response size, or a timing difference. With one you can often decrypt ciphertext without the key, or construct a ciphertext that decrypts to chosen plaintext when you can submit crafted preceding blocks or IVs and the application accepts the resulting validly padded message. In short, a system is exposed if it lets a client tell valid padding from invalid padding.

evidence: spctl --status
evidence: spctl --assess -v /Applications/App.app

answer:
`spctl --status` shows the status of Gatekeeper (`spctl` is the command-line tool for enumerating and interacting with Gatekeeper). HackTricks also notes that Gatekeeper's signature checks are performed only on files with the Quarantine attribute, not on every file, and that `syspolicyd` is the main daemon responsible for enforcing Gatekeeper, maintaining a database located in `/var/db/SystemPolicy`.
